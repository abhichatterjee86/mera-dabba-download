# Mera Dabba for Android

Save anything from any app - links, posts, photos and voice notes. Mera Dabba sorts it for you and reminds you on time. In English and 10 Indian languages.

**Download and install steps: https://meradabba.app/download**

This repository only holds the Android app file (APK) for download. The newest version is always here:
https://github.com/abhichatterjee86/mera-dabba-download/releases/latest/download/mera-dabba.apk

Each release also has a `.sha256` file, so you can check that the APK was not changed.
